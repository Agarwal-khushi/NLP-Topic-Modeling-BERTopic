# NLP-Topic-Modeling-BERTopic

## Project Overview
This project presents a Python-based NLP pipeline for extracting, preprocessing, and analyzing text from RTF documents. It applies BERTopic for topic modeling to discover hidden themes and identify globalization trends through automated text analysis.

## Features
- PDF Text Extraction
- Text Preprocessing
- BERTopic Topic Modeling
- Topic Visualization
- Globalization Analysis

## Technologies Used
- Python
- BERTopic
- Sentence Transformers
- Pandas
- NumPy
- Matplotlib
- HDBSCAN
- UMAP
